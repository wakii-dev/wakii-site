Wakii integrates **GitHub and Linear natively** — browse PRs, issues, and
project boards without leaving the app. Open a worktree straight from any
ticket and send the result back as a review.

## What you get

- **PR review** — diff view with inline comments, powered by the same
  engine as the Annotate AI diffs feature
- **Issue & board view** — Linear cycles, projects, and GitHub issues in
  one panel
- **Worktree from task** — click a ticket, get a worktree with the agent
  already pointed at it
- **Status sync** — agent progress posts back to the ticket

## Opening a worktree from a task

1. Open the **Reviews** panel and pick a ticket.
2. Click **Open worktree** — Wakii creates an isolated worktree named after
   the ticket and launches your default agent with the ticket context.
3. When the agent finishes, review the diff inline and merge.

## Status sync

Agents post progress updates back to the ticket as they complete phases —
spec, implementation, review — so the board reflects reality without manual
updates.

## Tips

- Filter the board by agent status to see which tickets have active agents.
- Use **Assign to agent** to hand a ticket to a specific CLI binary.
