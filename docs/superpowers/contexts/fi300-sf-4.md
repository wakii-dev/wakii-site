4. **reduced-motion-audit**: prefers-reduced-motion → 0 animation chạy trên mọi surface mới.

6. **cross-surface-visual-consistency**: so mọi surface vs hand-off `sf-downloads-direction.md` — tokens/structure/behavior khớp.
7. **e2e-flow**: browser thật đi trọn landing → /download → tab platform → click (hoặc follow) → mobile block → lang-switch — flow không đứt (RULE 0 3 tầng: DOM/VISUAL/FLOW).
