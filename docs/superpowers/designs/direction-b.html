Chapter 02 — Features

Not a chat window. A working team.

Every capability is one thread in the same story pipeline — from an idea spoken aloud to a pull request worth reviewing.

01

Story system

Epics decompose into spec slices — SF brackets — each with explicit scope, so nothing is built half-understood.

02

Bracket canvas

The whole story map lives on a canvas beside your editor: dependencies, progress, gates — visible at a glance.

03

Nine agents, gated

Coordinators, designers, executors, verifiers — with gates between every role. Nothing passes unchecked.

04

Watchdog

When work stalls or a hand-off goes unfinished, the watchdog notices — and drives it to completion on its own.

05

Memory loop

Decisions, verdicts and patterns persist across sessions. Your team doesn't start over — it gets sharper.

06

Figma, verified

Designs flow in, prototypes come out, and verifiers check the build against the source of truth — pixel by pixel.

Chapter 04 — Quickstart

Begin in three steps.

STEP I

Build Wakii

Clone the repository and build from source — one command, fully self-contained.

$ git clone wakii && make
STEP II

Open a project

The superpowers kit installs itself on first launch. There is nothing to configure.

$ wakii ./your-project
STEP III

Describe an idea

Chapter 05 — FAQ

Questions, answered plainly.

Is Wakii really zero-setup?

Yes. The plugin is bundled in the app and the skills kit installs itself to ~/.claude on first launch, enabled by default. Open Wakii — the team is already there.

How is this different from an AI plugin?

A plugin gives you a chat window. Wakii gives you a team: nine agents with defined roles, gates between them, a watchdog that completes stalled work, and memory that compounds across sessions.

What does "one PR per story" mean?

Each story — no matter how many agents or spec slices it takes — lands as one clean, reviewable pull request with verification behind it. No PR storms, no half-merged states.

What is Wakii's relationship to Orca?

Wakii is an open-source fork of Orca, which is MIT licensed. We credit the upstream project fully and build the superpowers team on top of it.
