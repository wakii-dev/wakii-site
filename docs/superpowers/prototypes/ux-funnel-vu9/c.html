##understand// answers 01–04 · no tour video

Four answers, then you decide.

▸what is it?// 01

Wakii is an open-source agentic IDE — a fork of Orca with a superpowers team built in. The plugin ships inside the app, the kit installs itself, and the whole thing is on by default: open a project and the team is already staffed.

Not a chat sidebar bolted onto an editor. The IDE, the panel and the workflow are one product.

fork of orca · plugin bundled · kit auto-installs into ~/.claude · on by default
▸who is it for?// 02

For developers who delegate. You hand over an idea; the team plans it in a bracket, builds it, and pushes the work through review gates B0–B5 while the watchdog keeps every agent honest.

idea → bracket → gates b0–b5 → 1 pr
