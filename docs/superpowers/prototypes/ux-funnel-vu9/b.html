##understand the 5-second layer · q1–q4 answered inline

Wakii is a free, open-source IDE — an Orca fork with a built-in superpowers team: nine AI agents that turn your ideas into verified pull requests.

q1 — what is wakii·plugin bundled in the app·kit auto-installs into ~/.claude·on by default — zero setup

01 · first-launch q2 — what do i see first?

The Superpowers panel, already live. Nine agents are online — roles assigned, watchdog armed — before you open a single file. The plugin ships inside the app, and on first run the kit installs itself into ~/.claude. Nothing to enable.

02 · built-for q3 — who is it for?

Developers who'd rather delegate the doing. Describe the idea in plain language — the team brackets it into sub-features, builds each one behind gates, and hands back one clean, verified pull request. You review a diff, not agent chatter.

bracket canvas — one story, its sub-features screenshot — placeholder frame
1 PR per story · gates b0–b5 · you review, you merge
03 · first-try q4 — what should i try first?

One command, typed into the app's chat input — it opens a story: the team brackets the work, builds each piece behind gates, and returns a verified branch for your review.

Smaller questions work too: /superpowers "why is this test flaky?"

$ /superpowers "add an RSS feed to the blog"
