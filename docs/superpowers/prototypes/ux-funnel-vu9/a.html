// q1 — what is wakii?

Wakii is an agentic IDE with a superpowers team built in.

A free, open-source fork of Orca. Nine agents plan, build, verify, and watch each other's work behind gates B0–B5. The plugin ships inside the app and the kit lands in ~/.claude on first run — zero setup steps.

9 agents
0 setup steps
1 PR per story
▸ q2 — open the app: what do you see first? team = online

The superpowers panel. All nine agents are already in there, marked online — each with a distinct role in one pipeline, and a watchdog on the floor. No wizard, no config file, nothing to toggle.

⚡ superpowers panel 9 agents online · watchdog active · zero-setup state
0 setup steps — the panel is live before your first click
▸ q3 — who is wakii for? delegate, don't drive

Devs who want to hand off the mechanical middle. You give Wakii an idea; the team brackets it, works it behind gates B0–B5, and hands back one clean, verified PR. You review the diff, not the process.

bracket canvas every story leaves a readable bracket — open it in the story view
1 PR per story — verified through gates B0–B5
▸ q4 — what should i try first? one command
wakii — first run
$ /superpowers "<your idea, one line>"
// e.g. /superpowers "add a /metrics endpoint — with tests"
→ team picked it up · bracket created · gates queued

In the superpowers panel, type /superpowers plus your idea. The team takes it from there: bracket, gates, PR. No flags, no config, no second command to learn.

That's the whole interface. Everything else — planning, verification, the watchdog — happens where you can watch it.
