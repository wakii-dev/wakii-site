## Là gì

AI code review CLI từ Alibaba (nội bộ 2 năm trước khi open-source): hybrid
**deterministic pipeline + LLM agent** — ruleset cứng cho bug class đã biết
(NPE, thread-safety, XSS, SQL injection), LLM chỉ đánh giá phần còn lại, output
comment anchored line-level với `suggestion_code` apply-được.

Con số marketing đáng chú ý (tự công bố, chưa độc lập): cùng model nền, precision
+ F1 cao hơn agent tổng quát, **~1/9 tokens**, recall thấp hơn *có chủ đích*
(precision-over-recall). Benchmark AACR-Bench: 50 repo OSS, 200 PR thật,
10 ngôn ngữ, 1,505 issue ground-truth do 80+ engineer annotate — public trên
HuggingFace (`Alibaba-Aone/aacr-bench`).

## Kiến trúc đáng học

- **Adaptive depth**: diff >50 lines mới bật plan/risk-analysis phase — review sâu chỉ tốn khi cần.
- **Context injection**: `--background` nhận business context để LLM phán theo intent, không chỉ theo diff.
- **Rule resolution 4 tầng**: `--rule` > repo `.opencodereview/rule.json` > user global > built-in; `merge_system_rule` cho phép cộng chứ không chỉ đè.
- **`ocr scan`**: whole-file audit mode tách khỏi diff review.
- **Delegate skill**: ship kèm 2 skills Claude Code (`open-code-review` + `-delegate`) — agent ngoài chạy tool này như một reviewer tier.
- `scripts/verify-action-pins.sh` — CI actions pinned by SHA (chuẩn OSSF Gold).
